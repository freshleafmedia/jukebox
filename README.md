A small, fast, collaborative, music player. We use it daily in the office. It runs on an ancient Raspberry Pi 2B.

Built with PHP, HTMX & SQlite.


## Install

```bash
git clone https://github.com/freshleafmedia/jukebox jukebox
cd jukebox
./install.sh
```

You will also need to [get a YouTube API key](https://console.cloud.google.com/apis/credentials) and put it in `config.php`.
